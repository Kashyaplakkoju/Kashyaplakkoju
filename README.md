## Featured: PrismForge

**A phone camera and presentation studio for Windows and Android.**

PrismForge began with a practical requirement: use the camera already in my pocket for streaming and recording, with more control over the image and presentation.

- **[V1 — Free community edition](https://github.com/Kashyaplakkoju/PrismForge-V1):** source code, Windows build, Android companion APK and setup guides. Includes phone-camera connectivity, colour/LUT tools, lighting and background effects for learning and experimentation.
- **V2 — Upcoming paid studio edition:** a redesigned interface, Windows and Android screen sharing, camera-over-screen presentations, an Android camera tile, moving video/GIF backgrounds, flexible framing and customizable glass themes. Microsoft Store preparation is underway; V2 is not live yet.

Camera and effects processing happens locally. V2's Windows webcam output uses separately installed OBS Virtual Camera.

I defined the requirements, directed the design and tested the Windows and Android experience, using Codex and Antigravity as AI development collaborators and building on open-source foundations.
